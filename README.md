# Laswo Studios

Marketing and enquiry site for Laswo Studios, an architectural design and build
practice based in Kitale, Kenya. Built with Django 4.2 and deployed on Render.

**Live:** https://laswo-final-project.onrender.com

---

## What it does

| Area | Purpose |
| --- | --- |
| **Pages** | Home, About, and the enquiry form that captures leads |
| **Services** | Five services, each with features and a linked enquiry CTA |
| **Projects** | Portfolio with per-project role, value and attribution |
| **Blog** | Articles with categories, tags, search and moderated comments |

Enquiries are stored in the database and appear under **Enquiries** in the admin,
with a follow-up status (New → Contacted → Quoted → Won / Closed). If SMTP
credentials are configured, a notification email is also sent; otherwise the
notification is written to the console and the enquiry is still saved.

## Running it locally

```bash
py -3.12 -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt
```

```bash
cp .env.example .env
```

```bash
DEBUG=True .venv/Scripts/python.exe manage.py migrate
```

Load the real services and project portfolio (safe to re-run — it matches on
slug and updates in place):

```bash
DEBUG=True .venv/Scripts/python.exe manage.py seed_site
```

```bash
DEBUG=True .venv/Scripts/python.exe manage.py createsuperuser
```

```bash
DEBUG=True .venv/Scripts/python.exe manage.py runserver
```

Run the tests:

```bash
.venv/Scripts/python.exe manage.py test
```

## Configuration

All configuration is environment-driven. Nothing secret is committed.

| Variable | Required | Notes |
| --- | --- | --- |
| `SECRET_KEY` | **Yes in production** | Falls back to an insecure development key |
| `DEBUG` | No | Defaults to `False`. Must stay `False` in production |
| `DATABASE_URL` | No | Postgres URL; falls back to local SQLite |
| `RENDER_EXTERNAL_HOSTNAME` | No | Injected by Render, appended to `ALLOWED_HOSTS` |
| `SECURE_SSL_REDIRECT` | No | Defaults to `True` when `DEBUG=False` |
| `EMAIL_HOST` etc. | No | Set to enable real enquiry notification emails |
| `ENQUIRY_NOTIFY_EMAIL` | No | Where enquiry notifications go |

Company contact details live in one place — `COMPANY` in
[`laswo_studios/settings.py`](laswo_studios/settings.py) — and are injected into
every template by `pages.context_processors.company`. Change a phone number
there and it updates across the whole site.

## Deployment

`render.yaml` and `build.sh` cover the Render setup. The build runs
`collectstatic` and `migrate`; the web process runs gunicorn.

`SECRET_KEY` is generated by Render and `DEBUG` is pinned to `False`.

### Known constraint: uploaded media

Portfolio images in `media/` are committed to the repository and served by the
app, so they survive deploys. **Images uploaded through the admin will not** —
Render's free disk is wiped on every deploy. Move media to object storage
(Cloudinary or S3) before relying on admin uploads in production.

## Portfolio attribution

Project pages state the role our founder held and, where relevant, the practice
the work was delivered with. Several projects were delivered with Eco Space
Architects. Please keep the `role` and `delivered_with` fields accurate when
adding new work — they are what make the portfolio honest.

The site describes Nicholas Ngeywo as an **architectural designer**, not an
architect. "Architect" is a title protected under Kenya's Architects and
Quantity Surveyors Act and should only be used with current BORAQS
registration.

## Notes

- Tailwind is loaded from its CDN. That keeps deployment simple but ships a
  larger payload than a compiled build; swap to the Tailwind CLI if page weight
  becomes a concern.
- `db.sqlite3` is not tracked in git. Production uses Postgres.
